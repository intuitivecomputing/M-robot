Learn how to install, set up the environment, and run the M Platform.

::tip
On the robot itself you don't build anything: M's software comes prebuilt in a Docker image. See [Running on the Robot](/intro/running-on-the-robot).
::

## Prerequisites

- **OS**: Ubuntu 22.04 (recommended)
- **ROS 2**: Humble Hawksbill or later
- **Python**: 3.10+
- **Hardware** (optional): M robot with servo motors, microphone, camera, and LED array. Set up its Raspberry Pi first with [Raspberry Pi Setup](/intro/raspberry-pi-setup).

## Installation

### 1. Clone the repository

The repository root is a colcon workspace (packages live under `src/`), so clone it straight into your workspace directory:

```bash
git clone https://github.com/intuitivecomputing/m-robot-files.git m_ws
cd m_ws
```

### 2. Install ROS 2 dependencies

```bash
rosdep install --from-paths src --ignore-src -r -y
```

### 3. Build the workspace

```bash
colcon build --symlink-install
```

### 4. Source the workspace

```bash
source install/setup.bash
```

### 5. Set API credentials

The speech and LLM nodes call cloud services and read their credentials from the environment. Set the ones for the services you use:

```bash
export OPENAI_API_KEY=...        # OpenAI TTS and LLM examples
export GROQ_API_KEY=...          # Groq LLM provider
export GOOGLE_APPLICATION_CREDENTIALS=/path/to/service-account.json  # Google TTS / ASR
```

::warning
Never commit API keys or service-account files to the repository.
::

## Running the Platform

### Launch the motor control system

```bash
ros2 launch motor_control motor_control_exec.launch.py
```

### Launch the audio pipeline

```bash
ros2 launch audio_processing audio_pipeline.launch.py
```

### Launch the video recording system

```bash
ros2 launch video_processing recording_system.launch.py
```

## Running an Application

### Story Teller

```bash
ros2 run story_teller story_delivery --ros-args -p story_filename:=chunked.json
```

### Positivity Psych Coach

```bash
ros2 launch positivity_pysch_coach enhanced_conversation_interaction.launch.py
```
