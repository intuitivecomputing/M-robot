M is an open-source, low-cost socially assistive robot platform designed to reduce platform friction that slows SAR research by making robots easier to reproduce, modify, and deploy in real-world settings.

## What is M?

M combines a modular mechanical design, multimodal sensing, and expressive but mechanically simple actuation with a ROS 2-native software architecture that cleanly separates perception, expression control, and data management.

The platform includes a simulation environment with interface equivalence to hardware, supporting rapid sim-to-real transfer of interaction behaviors.

## Key Capabilities

- **Modular Mechanical Design** — Easy to reproduce and modify with off-the-shelf components
- **Multimodal Sensing** — Microphone arrays, cameras, and configurable sensor pipelines
- **Expressive Actuation** — Motor-driven expressions with face display and LED indicators
- **ROS 2-Native Architecture** — Clean separation of perception, expression, and data layers
- **Simulation Environment** — Interface-equivalent simulation for rapid prototyping
- **Extensible Application Layer** — Templates for storytelling, conversational coaching, and custom interaction domains

## Platform Packages

| Package | Description |
| --- | --- |
| `motor_control` | Joint position control, trajectory execution, motor primitives |
| `audio_processing` | Microphone streaming, ASR, TTS, VAD, audio playback |
| `video_processing` | Camera streaming, video recording, session coordination |
| `m_commons` | Shared utilities — startup manager, configuration, face/LED controllers |
| `m_interfaces` | Custom ROS 2 service and action definitions |
| `story_teller` | Interactive story delivery application |
| `positivity_pysch_coach` | Conversational coaching for positive psychology |
| `m_examples` | Example integrations — behavior generation, LLM providers |

## Real-World Use

M has been validated in participatory design sessions and week-long in-home deployments, demonstrating its viability as a practical foundation for longitudinal, reproducible socially assistive robotics research.
