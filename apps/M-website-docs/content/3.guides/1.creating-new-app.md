# Creating a New App

This guide walks through creating a new application package that integrates with the M Platform's core services.

## 1. Create the Package

Use the ROS 2 CLI to scaffold a new Python package:

```bash
cd /root/m_ws/src
ros2 pkg create --build-type ament_python my_app \
  --dependencies rclpy std_msgs m_interfaces m_commons
```

This creates the standard directory structure:

```text
my_app/
├── my_app/
│   ├── __init__.py
│   └── my_node.py
├── launch/
├── config/
├── resource/
├── setup.py
├── setup.cfg
└── package.xml
```

## 2. Create the Main Node

Your node should follow the state-machine pattern used by `story_delivery` and `conversation_orchestrator`:

```python
import rclpy
from rclpy.node import Node
from rclpy.executors import MultiThreadedExecutor
from std_msgs.msg import Bool, String

class MyAppNode(Node):
    def __init__(self):
        super().__init__("my_app_node")

        # Declare parameters
        self.declare_parameter("my_param", "default_value")

        # Publishers
        self.pub_speaking = self.create_publisher(Bool, "robot_speaking", 10)

        # Subscriptions
        self.create_subscription(String, "asr_text", self.on_asr, 10)

        # Use core services
        # AnimationScheduler for face + body coordination
        from m_commons.animation import AnimationScheduler
        self._animation = AnimationScheduler(self)

        self.get_logger().info("MyAppNode ready")

    def on_asr(self, msg: String):
        self.get_logger().info(f"User said: {msg.data}")

def main(args=None):
    rclpy.init(args=args)
    node = MyAppNode()
    executor = MultiThreadedExecutor()
    executor.add_node(node)
    try:
        executor.spin()
    finally:
        executor.remove_node(node)
        node.destroy_node()
        rclpy.shutdown()
```

## 3. Use Core Services

Your app can call any of the platform's core services:

| Service | Usage |
| --- | --- |
| `tts_synthesize` | Convert text to audio via `TextToSpeech` |
| `faster_whisper_transcribe` | Get ASR transcription via `TranscribeAudio` |
| `set_pose` / `execute_primitive` | Control motors |
| `audio_play` | Play audio via the `AudioPlay` action |
| `control_led` | Toggle LED indicator |

## 4. Add a Launch File

Create `launch/my_app.launch.py`:

```python
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(
            package='my_app',
            executable='my_app_node',
            name='my_app_node',
            parameters=[{'my_param': 'value'}],
        ),
    ])
```

## 5. Register Entry Points

In `setup.py`, register your node and launch file:

```python
entry_points={
    'console_scripts': [
        'my_app_node = my_app.my_node:main',
    ],
},
data_files=[
    (os.path.join('share', package_name, 'launch'), glob('launch/*.launch.py')),
],
```

## 6. Build and Run

```bash
cd /root/m_ws
colcon build --packages-select my_app --symlink-install
source install/setup.bash
ros2 launch my_app my_app.launch.py
```

## 7. Register with Startup Manager

Add your node to the startup manager's `required_nodes` parameter so it participates in the coordinated boot sequence:

```bash
ros2 run m_commons startup_manager --ros-args \
  -p required_nodes:="['my_app_node', 'face_controller', 'audio_playback']"
```
