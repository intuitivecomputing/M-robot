This guide explains how to add new motor primitives, modify existing gestures, and create keyframe sequences for the M Platform.

## Motor Configuration File

Motor behaviors are defined in the motor controller config:

```text
/root/m_ws/src/motor_control/config/config.json
```

The file contains motor definitions (channels, ranges, servo specs) and named primitive functions.

## Available Joints

| Joint | Range (°) | Description |
| --- | --- | --- |
| `base_rotation` | -120 to 120 | Rotate the base left/right |
| `head_pitch` | -40 to 40 | Tilt head up/down |
| `head_yaw` | -90 to 90 | Turn head left/right |
| `arm_left` | -45 to 135 | Move left arm |
| `arm_right` | -45 to 135 | Move right arm |

## Adding a New Primitive

Primitives are Python functions in `motor_control/motor_primitives.py` that return keyframe sequences. To add a new one:

### 1. Define the Function

```python
def my_wave(amplitude=45.0, duration=2.0):
    """Wave gesture using the right arm."""
    return [
        {"at": 0.0, "duration": 0.5, "pose": {"arm_right": amplitude}},
        {"at": 0.5, "duration": 0.5, "pose": {"arm_right": -amplitude}},
        {"at": 1.0, "duration": 0.5, "pose": {"arm_right": amplitude}},
        {"at": 1.5, "duration": 0.5, "pose": {"arm_right": 0.0}},
    ]
```

### 2. Register the Primitive

Add it to the primitives dictionary in `motor_controller.py` so it can be called via the `execute_primitive` service.

### 3. Test via CLI

```bash
ros2 service call /execute_primitive m_interfaces/srv/ExecutePrimitive \
  "{function_name: 'my_wave', param_names: ['amplitude'], param_values: ['60.0'], start_at: 0.0}"
```

## Creating Keyframe Sequences

Keyframe sequences can be sent directly via the `play_pose_sequence` service without registering a primitive:

```bash
ros2 service call /play_pose_sequence m_interfaces/srv/PlayPoseSequence \
  "{at: [0.0, 1.0, 2.0], duration: [0.8, 0.8, 0.8], \
   joint_names: ['head_yaw', 'head_pitch'], \
   joint_angles: [30.0, 10.0, -30.0, -10.0, 0.0, 0.0]}"
```

This moves the head right-and-down, then left-and-up, then back to neutral.

## Using with AnimationScheduler

For application-level behavior, use `AnimationScheduler` to coordinate body movements with face expressions:

```python
from m_commons.animation import AnimationScheduler
from m_commons.story_models import AnimationCue, BodyTimeline
import json

scheduler = AnimationScheduler(node)

# Schedule a face expression
scheduler.schedule_face_program(
    AnimationCue(program_json='{"program": "happy"}', delay=0.0)
)

# Schedule a body timeline
timeline_json = json.dumps([
    {"at": 0.0, "duration": 1.0, "pose": {"head_yaw": 20.0, "arm_left": 45.0}},
    {"at": 1.5, "duration": 1.0, "pose": {"head_yaw": 0.0, "arm_left": 0.0}},
])
scheduler.schedule_body_timeline(
    BodyTimeline(timeline_json=timeline_json, delay=0.5)
)
```

## LLM-Driven Behaviors

Use the `BehaviorGenerator` from `m_examples` to generate expressions and primitives from text:

```python
from m_examples.behavior_generator import BehaviorGenerator

gen = BehaviorGenerator()
behaviors = gen.generate_behaviors(["I'm so happy to see you!"])
# [{"segmentID": 0, "expression": "happy", "primitive": "open_encourage"}]
```

See the [Behavior Generator](/api/examples/behavior-generator) docs for details.
