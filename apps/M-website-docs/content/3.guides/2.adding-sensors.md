This guide explains how to add a new hardware sensor to the M Platform with proper lifecycle integration.

## 1. Create a ROS 2 Node

Wrap the sensor SDK in a ROS 2 node. Follow the pattern from `camera_streamer` or `mic_streamer`:

```python
import rclpy
from rclpy.node import Node
from std_msgs.msg import Float32MultiArray
from m_interfaces.srv import ControlLED

class MySensor(Node):
    def __init__(self):
        super().__init__("my_sensor")

        # Declare configurable parameters
        self.declare_parameter("device_path", "/dev/ttyUSB0")
        self.declare_parameter("sample_rate", 100)

        # Publisher for sensor data
        self._pub = self.create_publisher(Float32MultiArray, "my_sensor/data", 10)

        # Optional: LED integration
        self._led_client = self.create_client(ControlLED, "control_led")

        # Start capture timer
        rate = self.get_parameter("sample_rate").value
        self.create_timer(1.0 / rate, self._read_and_publish)

        self.get_logger().info("MySensor ready")

    def _read_and_publish(self):
        # Read from hardware and publish
        msg = Float32MultiArray()
        msg.data = [0.0]  # Replace with actual sensor reading
        self._pub.publish(msg)
```

## 2. Expose a NodeReady Service

To participate in the startup sequence, add a `NodeReady` service:

```python
from m_interfaces.srv import NodeReady

class MySensor(Node):
    def __init__(self):
        super().__init__("my_sensor")
        # ... sensor setup ...

        self._ready = False
        self.create_service(NodeReady, "my_sensor/node_ready", self._node_ready_cb)

        # Mark ready once hardware is initialized
        self._ready = True

    def _node_ready_cb(self, request, response):
        response.ready = self._ready
        response.message = "OK" if self._ready else "Initializing"
        return response
```

## 3. Register with Startup Manager

Add your node to the `required_nodes` list:

```bash
ros2 run m_commons startup_manager --ros-args \
  -p required_nodes:="['my_sensor', 'face_controller', 'audio_playback']"
```

## 4. Add to Launch Files

Create or update a launch file to include your sensor:

```python
from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(
            package='my_sensor_pkg',
            executable='my_sensor',
            parameters=[{
                'device_path': '/dev/ttyUSB0',
                'sample_rate': 100,
            }],
        ),
    ])
```

## 5. Build and Test

```bash
colcon build --packages-select my_sensor_pkg --symlink-install
source install/setup.bash
ros2 run my_sensor_pkg my_sensor

# Verify data is flowing
ros2 topic echo /my_sensor/data
```

## Tips

- Use `ControlLED` to provide visual feedback when your sensor is active
- Follow the `camera_streamer` pattern for cleanup in `destroy_node()`
- Declare all hardware-specific values as ROS parameters for easy reconfiguration
