# Hardware BOM

::tip
The canonical, priced parts list is the [Bill of Materials](https://m-robot-platform.vercel.app/bill-of-materials) on the project website. It includes quantities and vendor links. Assembly is covered step by step in the [Build Guide](https://m-robot-platform.vercel.app/build-guide), and the 3D-printable parts are in the CAD files linked from the website.
::

This page describes how the software expects that hardware to be wired and configured.

## Actuation

All joints are driven by a PCA9685 16-channel PWM servo driver at I2C address `0x40`.

| Joint | PCA9685 channel |
| --- | --- |
| Base rotation | 0 |
| Head pitch | 2 |
| Head yaw | 4 |
| Left arm | 8 |
| Right arm | 10 |

The arms are optional. See the Bill of Materials for which servo goes on which joint.

## Sensing

| Device | Software expectation |
| --- | --- |
| Camera | V4L2 device, default `/dev/video10`, 640×480 @ 30 fps |
| ReSpeaker Lite | 2-channel, 16 kHz audio input |

## Feedback

| Device | Software expectation |
| --- | --- |
| Face display | Web-based face served at `localhost:3001`, driven by `face_controller` |
| LED indicator | GPIO pin 24, controlled via `lgpio` |
