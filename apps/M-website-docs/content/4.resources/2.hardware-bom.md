This page describes how the software expects that hardware to be wired and configured.

## Actuation

All joints are driven by a PCA9685 16-channel PWM servo driver at I2C address `0x40`.

| Joint | PCA9685 channel |
| --- | --- |
| Base rotation | 0 |
| Head pitch | 2 |
| Head yaw | 4 |
| Left arm | 8 |
| Right arm | 10 |

The arms are optional. See the Bill of Materials for which servo goes on which joint.

## Sensing

| Device | Software expectation |
| --- | --- |
| Camera | V4L2 device, default `/dev/video10`, 640×480 @ 30 fps, created by `setup_M.sh` (see [Raspberry Pi Setup](/intro/raspberry-pi-setup)) |
| ReSpeaker Lite | 2-channel, 16 kHz audio input |

## Feedback

| Device | Software expectation |
| --- | --- |
| Face display | Web-based face served at `localhost:3001`, driven by `face_controller` |
| LED indicator | GPIO pin 24, controlled via `lgpio` |

## Software Dependencies

On the robot, the Raspberry Pi runs Raspberry Pi OS and the ROS 2 software runs in Docker. [Raspberry Pi Setup](/intro/raspberry-pi-setup) installs everything the Pi itself needs.

| Software | Version | Purpose |
| --- | --- | --- |
| Raspberry Pi OS | Legacy, 64-bit (Debian Bookworm) | The robot's operating system |
| Ubuntu | 22.04 | ROS 2 environment (in Docker on the robot) |
| ROS 2 | Humble Hawksbill | Robotics middleware |
| Python | 3.10+ | Node runtime |
| OpenCV | 4.x | Camera capture |
| ffmpeg | — | Audio/video muxing |
| simpleaudio | — | Audio playback |
| pydub | — | Audio format conversion |
