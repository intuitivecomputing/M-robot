The M Platform is fully open source. The robot software, the documentation, and the hardware resources are all public.

## Repositories

- **Robot software**: [github.com/intuitivecomputing/m-robot-files](https://github.com/intuitivecomputing/m-robot-files)
- **Project website and docs**: [github.com/intuitivecomputing/M-robot](https://github.com/intuitivecomputing/M-robot)
- **Project website**: [intuitivecomputing.github.io/M-robot](https://intuitivecomputing.github.io/M-robot/). It hosts the build guide, bill of materials, and CAD files.

## Repository Layout

| Path | Contents |
| --- | --- |
| `src/` | The ROS 2 packages, as a colcon workspace (see the package index below) |
| `setup_M.sh` | Sets up the robot's Raspberry Pi (see [Raspberry Pi Setup](/intro/raspberry-pi-setup)) |
| `m-motor-control/` | Servo calibration and test scripts, and their Python requirements |
| `face-server/` | The web server that renders M's face on its screen, on port 3001 |
| `pilot-deployment/` | Launch scripts and systemd services from the in-home pilot deployment |

## Package Index

| Package | Path | Description |
| --- | --- | --- |
| `motor_control` | `src/motor_control` | Joint position control, trajectory execution, motor primitives |
| `audio_processing` | `src/audio_processing` | Microphone streaming, ASR, TTS, VAD, audio playback |
| `video_processing` | `src/video_processing` | Camera streaming, video recording, session coordination |
| `m_commons` | `src/m_commons` | Shared utilities — startup manager, configuration, animation, face/LED controllers |
| `m_interfaces` | `src/m_interfaces` | Custom ROS 2 service and action definitions |
| `m_logging` | `src/m_logging` | Conversation logging |
| `story_teller` | `src/story_teller` | Interactive story delivery application |
| `positivity_pysch_coach` | `src/positivity_pysch_coach` | Conversational positive psychology coaching |
| `m_examples` | `src/m_examples` | Example integrations — behavior generation, LLM providers |

## Documentation Source

The documentation site is built with [Docus](https://docus.dev) (Nuxt-based) and lives in the website repository at:

```text
apps/M-website-docs/
```

## Building from Source

```bash
git clone https://github.com/intuitivecomputing/m-robot-files.git m_ws
cd m_ws
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
```
