## Third-Party Dependencies

The platform uses the following third-party libraries and services:

| Dependency | License | Usage |
| --- | --- | --- |
| ROS 2 (Humble) | Apache 2.0 | Robotics middleware |
| Faster Whisper | MIT | Speech-to-text (ASR) |
| Google Cloud TTS | Proprietary (API) | Text-to-speech synthesis |
| OpenAI API | Proprietary (API) | LLM for coaching and behavior generation |
| Groq API | Proprietary (API) | LLM for behavior generation |
| OpenCV | Apache 2.0 | Camera capture and video processing |
| pydub | MIT | Audio format conversion |
| simpleaudio | MIT | Audio playback |
| sounddevice | MIT | Microphone streaming |
| lgpio | MIT | GPIO LED control |
