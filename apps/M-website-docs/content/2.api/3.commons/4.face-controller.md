# Face Controller

HTTP-based face expression controller that subscribes to `face_expression` and forwards commands to a web-based face display. Detailed documentation is available on the [Robot Feedback](/api/core/robot-feedback) page.

## Module

- **Package**: `m_commons`
- **Module**: `m_commons.face_controller`
- **Node**: `face_controller`
- **Entry point**: `m_commons.face_controller:main`

## Topic

| Topic | Type | Direction | Description |
| --- | --- | --- | --- |
| `face_expression` | `std_msgs/String` | Subscribes | Expression name or `exec:` program |

## Modes

- **Expression mode** — Publish a named expression string (e.g., `happy`, `sad`, `neutral`) → sent via POST to `express_url`
- **Exec mode** — Publish `exec:{program_name}` → sent via POST to `exec_func_url`

## Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `express_url` | `string` | `http://localhost:3001/express` | URL for expression commands |
| `exec_func_url` | `string` | `http://localhost:3001/exec-func` | URL for executable animation programs |
| `request_timeout` | `double` | `2.0` | HTTP request timeout in seconds |
