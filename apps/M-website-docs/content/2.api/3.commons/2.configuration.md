Shared configuration helpers that load ROS 2 parameters and environment variables into typed, validated dataclasses.

## Module

- **Package**: `m_commons`
- **Module**: `m_commons.configuration`

## ConfigurationError

A custom `RuntimeError` subclass raised when configuration parameters are invalid or required files cannot be found.

```python
from m_commons.configuration import ConfigurationError
```

## StoryManagerConfig

Frozen dataclass that manages story asset paths, log directories, and session identifiers.

### Fields

| Field | Type | Default Source | Description |
| --- | --- | --- | --- |
| `story_search_paths` | `List[Path]` | ROS param or `/root/m_ws/src/story_teller/stories` | Directories to search for story JSON files |
| `log_directory` | `Path` | `ROBOT_LOG_DIR` env var or `~/.ella/logs` | Directory for session logs |
| `default_story` | `str` | ROS param or `chunked.json` | Default story filename |
| `session_id` | `str` | `SESSION_ID` env var or `session_unknown` | Current session identifier |

### Factory Method

```python
config = StoryManagerConfig.from_node(ros_node)
```

Builds the config by declaring and reading ROS parameters. The `log_directory` is created automatically if it does not exist.

### Path Resolution

```python
path = config.resolve_story_path("my_story.json")
```

Resolves a filename against the configured search paths:

1. If the filename is an absolute path that exists, return it directly
2. Otherwise, search each directory in `story_search_paths`
3. Raises `ConfigurationError` if not found

## Helper Functions

### `_expand_paths`

Internal utility that expands `~` and resolves a sequence of path strings into a list of absolute `Path` objects. Empty strings are skipped.
