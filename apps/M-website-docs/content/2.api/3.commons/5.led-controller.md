GPIO-based LED controller for Raspberry Pi with automatic simulation mode fallback. Detailed documentation is available on the [Robot Feedback](/api/core/robot-feedback) page.

## Module

- **Package**: `m_commons`
- **Module**: `m_commons.led_controller`
- **Node**: `led_controller`
- **Entry point**: `m_commons.led_controller:main`
- **GPIO Pin**: 24 (configurable via `LED_PIN` class attribute)

## Service

| Service | Type | Description |
| --- | --- | --- |
| `control_led` | `ControlLED` | Toggle LED on/off |

## Service Interface

- **Request**: `enabled` (`bool`) — `true` to turn on, `false` to turn off
- **Response**: `success` (`bool`), `message` (`string`)

## Hardware / Simulation

- Uses `lgpio` library for GPIO control on Raspberry Pi
- Falls back to simulation mode (log-only) when `lgpio` is not available
- LED is turned off on node shutdown

## Consumers

The following nodes call `control_led` automatically:

- `mic_streamer` — LED on when streaming, off on shutdown
- `camera_streamer` — LED on when streaming, off on shutdown
