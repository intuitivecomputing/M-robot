# Animation

The `AnimationScheduler` class coordinates facial expressions and body poses using delayed one-shot ROS timers. It is the primary mechanism for synchronizing motor actions with audio during story delivery and other interactions.

## Module

- **Package**: `m_commons`
- **Module**: `m_commons.animation`
- **Class**: `AnimationScheduler`

## Constructor

```python
from m_commons.animation import AnimationScheduler

scheduler = AnimationScheduler(node, callback_group=None)
```

Creates a publisher on `face_expression` and a client for the `set_pose` service.

## Methods

| Method | Description |
| --- | --- |
| `schedule_face_program(cue)` | Schedule a face program to execute after `cue.delay` seconds |
| `schedule_body_timeline(timeline)` | Schedule a body timeline (parsed from JSON) with per-keyframe delays |
| `clear()` | Cancel all scheduled animations without resetting pose |
| `reset_to_neutral()` | Cancel animations, reset face to `"reset"`, and send neutral body pose |
| `shutdown()` | Cancel timers and drop outstanding references |

## Face Programs

Face programs are scheduled via `AnimationCue` objects:

```python
from m_commons.story_models import AnimationCue

cue = AnimationCue(program_json='{"program": "waking_up"}', delay=0.5)
scheduler.schedule_face_program(cue)
```

The scheduler publishes `exec:{program_name}` to the `face_expression` topic after the specified delay.

## Body Timelines

Body timelines are JSON arrays of keyframes, each with a pose dictionary, duration, and time offset:

```json
[
  {"at": 0.0, "duration": 1.0, "pose": {"head_yaw": 30.0, "arm_left": 45.0}},
  {"at": 1.5, "duration": 0.8, "pose": {"head_yaw": -30.0, "arm_right": 45.0}}
]
```

Each keyframe is scheduled as a separate `set_pose` service call at `timeline.delay + entry.at` seconds.

## Neutral Pose

The neutral pose resets all joints to zero:

```python
{
    "base_rotation": 0.0,
    "head_pitch": 0.0,
    "arm_left": 0.0,
    "arm_right": 0.0,
    "head_yaw": 0.0,
}
```

## Usage

The `StoryDelivery` node uses `AnimationScheduler` to coordinate face and body animations with each narrative chunk's audio playback.
