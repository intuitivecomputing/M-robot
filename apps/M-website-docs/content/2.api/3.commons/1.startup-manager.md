# Startup Manager

Orchestrates the startup sequence by polling required nodes for readiness, playing a waking animation during boot, and signaling when all nodes are operational.

## Module

- **Package**: `m_commons`
- **Entry point**: `m_commons.startup_manager:main`
- **Node name**: `startup_manager`

## Architecture

The startup manager is composed of four internal components:

| Component | Class | Purpose |
| --- | --- | --- |
| State machine | `StartupStateMachine` | Tracks `INITIALIZING` → `WAITING_FOR_NODES` → `ANIMATION_COMPLETE` → `READY` / `FAILED` |
| Readiness tracker | `NodeReadinessTracker` | Tracks which required nodes have reported ready |
| Readiness poller | `ReadinessPoller` | Creates `NodeReady` service clients and polls nodes concurrently |
| Animation controller | `AnimationController` | Publishes waking animation on `face_expression` during boot |

## Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `required_nodes` | `string[]` | `[face_controller, expression_controller, conversation_orchestrator, audio_playback]` | Nodes to wait for before declaring ready |
| `polling_interval_ms` | `int` | `500` | How often to poll nodes (milliseconds) |
| `max_startup_time_s` | `double` | `30.0` | Maximum time to wait before declaring failure |
| `poll_timeout_s` | `double` | `2.0` | Per-node service call timeout |

## Service

| Service | Type | Description |
| --- | --- | --- |
| `startup_manager/node_ready` | `NodeReady` | External readiness check — returns `true` once all nodes are ready |

## Startup Flow

1. Node enters `INITIALIZING` state
2. Transitions to `WAITING_FOR_NODES` and starts polling timer
3. On first poll, the waking animation is published to `face_expression`
4. Each required node is polled via its `/{node_name}/node_ready` service
5. As nodes report ready, they are tracked in the readiness set
6. If all nodes are ready → transitions to `READY` and resets animation
7. If `max_startup_time_s` is exceeded → transitions to `FAILED` with error log

## Usage

```bash
ros2 run m_commons startup_manager --ros-args \
  -p required_nodes:="['face_controller', 'audio_playback']" \
  -p max_startup_time_s:=60.0
```
