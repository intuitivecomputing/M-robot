title: Service Types
description: Custom ROS 2 service interface definitions used across the M Platform.
---

All custom ROS 2 service interfaces are defined in the `m_interfaces` package under `srv/`.

## SetPose

Move joints to a target position.

```text
# Request
string[]  joint_names
float32[] joint_angles
float32   duration
---
# Response
bool   success
string message
```

## PlayPoseSequence

Execute queued multi-frame keyframe sequences using flattened arrays.

```text
# Request
float32[] at             # seconds-from-start for each key-frame (length N)
float32[] duration       # duration of each key-frame (length N)
string[]  joint_names    # global joint order (length J)
float32[] joint_angles   # flattened: length N * J
---
# Response
bool   success
string message
```

## ExecutePrimitive

Trigger a named motor behavior function with parameters.

```text
# Request
string   function_name
string[] param_names
string[] param_values
float32  start_at
---
# Response
bool   success
string message
```

## TextToSpeech

Request TTS synthesis, returning Base64-encoded MP3 audio.

```text
# Request
string text
---
# Response
string audio_base64
bool   success
string error_message
```

## TranscribeAudio

Request speech-to-text transcription from Base64-encoded audio.

```text
# Request
string base64_audio
---
# Response
string transcript
```

## ControlLED

Toggle the LED indicator on or off.

```text
# Request
bool enabled
---
# Response
bool   success
string message
```

## NodeReady

Check if a node has completed initialization.

```text
# Request
string node_name
---
# Response
bool   ready
string message
```

```text

---
```
