All custom ROS 2 action interfaces are defined in the `m_interfaces` package under `action/`.

## AudioPlay

Non-blocking audio playback with progress feedback. Used by `audio_playback_action` node.

```text
# Goal
uint8[] data          # Raw WAV/PCM bytes

---
# Result
int32  result_code    # 0 = OK, 1 = canceled, 2 = error
string message        # Optional human-readable status

---
# Feedback
float32 progress      # 0–100 percentage of audio played
```

### Result Codes

| Code | Meaning |
| --- | --- |
| `0` | Playback completed successfully |
| `1` | Playback was canceled by client |
| `2` | Playback error (decode failure, device error) |

## Reserved / Unused Actions

The following actions are defined but not yet actively used:

### DeliverResponse

Deliver text with coordinated gestures and expressions.

```text
# Goal
string text

---
# Result
int32   result_code
string  message
float32 duration          # Total delivery duration in seconds

---
# Feedback
float32 progress          # Overall progress 0–100%
string  current_state     # e.g., "generating_behaviour", "executing_response"
float32 audio_progress    # Audio playback progress 0–100%
```

### RealtimeDeliverResponse

Stream segmented delivery with per-segment progress tracking.

```text
# Goal
string delivery_packet_json   # JSON array of segments

---
# Result
int32   result_code
string  message
float32 duration
int32   segments_completed

---
# Feedback
float32 progress              # Overall progress 0–100%
string  current_state         # e.g., "processing_segment", "playing_audio"
int32   current_segment       # Current segment index (0-based)
float32 segment_progress      # Current segment progress 0–100%
```
