# Video System

The `video_processing` package provides camera streaming, video recording with synchronized audio capture, and post-recording ffmpeg muxing.

## Package Overview

| Entry Point | Node | Purpose |
| --- | --- | --- |
| `camera_streamer` | `camera_streamer` | Stream camera frames via ROS 2 Image topic |
| `video_saver` | `video_saver` | Record synchronized video + audio to MP4 |
| `recording_controller` | — | High-level recording control |
| `session_recording_coordinator` | — | Coordinate recording across sessions |

## Camera Streamer

Captures frames from an OpenCV-compatible camera and publishes them as ROS 2 `Image` messages.

- **Node**: `camera_streamer`
- **Publishes**: `camera/image_raw` (`sensor_msgs/Image`)
- **LED integration**: Turns LED on at start, off at shutdown

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `device_path` | `string` | `/dev/video10` | V4L2 camera device path |
| `width` | `int` | `640` | Frame width in pixels |
| `height` | `int` | `480` | Frame height in pixels |
| `fps` | `int` | `30` | Capture frame rate |
| `fourcc` | `string` | `YUYV` | Video capture format (FOURCC code) |

## Video Saver

Records video and audio streams with direct-write architecture and post-recording ffmpeg muxing.

- **Node**: `video_saver`
- **Subscribes**: `camera/image_raw` (`Image`), `mic_audio` (`Float32MultiArray`)
- **Services**: `start_recording` (`SetBool`), `stop_recording` (`SetBool`)

### Architecture

- Video frames written immediately to OpenCV `VideoWriter` (no buffering)
- Audio frames streamed directly to WAV file
- Thread-safe via `Lock` synchronization
- Post-recording: ffmpeg muxes video + audio into MP4

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `output_directory` | `string` | `/root/m_ws/data` | Output directory for recordings |
| `video_fps` | `int` | `30` | Video frame rate |
| `audio_rate` | `int` | `16000` | Audio sample rate (Hz) |
| `video_codec` | `string` | `XVID` | Video codec (XVID, MJPG, H264) |
| `audio_bitrate` | `int` | `128` | Audio bitrate for final MP4 (kbps) |
| `video_bitrate` | `int` | `2000` | Video bitrate for final MP4 (kbps) |

### Recording Flow

1. Call `start_recording` with `data: true` — initializes video/audio writers with timestamped filenames
2. Frames and audio are written in real-time as they arrive
3. Call `stop_recording` — closes writers, runs ffmpeg to mux into `recording_YYYY-MM-DD_HH-MM-SS.mp4`
4. Temporary `.avi` and `.wav` files are cleaned up on success

### Statistics

The node tracks frame drops and audio errors during recording, logged when recording stops.

## Launch Files

```bash
ros2 launch video_processing recording_system.launch.py
```
