The `audio_processing` package provides a full audio pipeline — microphone streaming, multiple ASR backends, TTS synthesis, voice activity detection, and non-blocking audio playback.

## Package Overview

All nodes are defined in the `audio_processing` package:

| Entry Point | Node | Purpose |
| --- | --- | --- |
| `mic_streamer` | `mic_streamer` | Stream live microphone audio |
| `faster_whisper_asr` | `faster_whisper_asr_service` | Whisper-based ASR with word timestamps |
| `google_asr` | — | Google Cloud streaming ASR |
| `silero_vad` | — | Silero voice activity detection |
| `turn_end_detector` | — | Detect end of user speech turns |
| `google_tts` | `google_tts_service` | Google Cloud TTS synthesis |
| `openai_tts` | — | OpenAI TTS synthesis |
| `audio_playback` | `audio_playback_action` | Non-blocking audio playback action |
| `audio_saver` | — | Save audio streams to disk |
| `audio_transcriber` | — | Batch audio transcription |

## Microphone Streaming

Streams live audio from the system microphone to a ROS 2 topic using `sounddevice`.

- **Node**: `mic_streamer`
- **Publishes**: `mic_audio` (`Float32MultiArray`) at 30 Hz queue depth
- **Sample rate**: 16 kHz
- **Chunk size**: 1024 samples per frame
- **Channels**: 2 (stereo input, publishes channel 0)
- **LED integration**: Automatically turns LED on at start, off at shutdown via `control_led` service

## Speech-to-Text (ASR)

### Faster Whisper ASR

Provides transcription with **word-level timestamps** using the Faster Whisper model.

- **Node**: `faster_whisper_asr_service`
- **Service**: `faster_whisper_transcribe` (`TranscribeAudio`)
- **Model**: `tiny` (CPU, int8 quantization)
- **Language**: English
- **Input**: Base64-encoded audio data
- **Output**: Timestamped transcript (e.g., `<0.12> Hello <0.45> world`)

### Google Streaming ASR

Alternative ASR backend using Google Cloud Speech-to-Text streaming API.

- **Entry point**: `google_asr`

## Text-to-Speech (TTS)

### Google Cloud TTS

Converts text to Base64-encoded MP3 audio using Google Cloud Text-to-Speech.

- **Node**: `google_tts_service`
- **Service**: `tts_synthesize` (`TextToSpeech`)
- **Voice**: `en-US-Chirp3-HD-Zephyr`
- **Speaking rate**: 0.75×
- **Output format**: Base64-encoded MP3
- **Requires**: `GOOGLE_APPLICATION_CREDENTIALS` environment variable

### OpenAI TTS

Alternative TTS backend using OpenAI's API.

- **Entry point**: `openai_tts`

## Audio Playback

Non-blocking `AudioPlay` action server that streams WAV data to the system audio device with progress feedback and cancel support.

- **Node**: `audio_playback_action`
- **Action**: `audio_play` (`AudioPlay`)
- **Goal**: Raw WAV bytes
- **Result codes**: `0` = success, `1` = canceled, `2` = error
- **Feedback**: Progress 0–100%

### Parameters

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `feedback_rate_hz` | `double` | `4.0` | How often to publish progress feedback |
| `volume` | `double` | `1.0` | Linear gain applied before playback |
| `device_name` | `string` | `"default"` | Audio output device |

Audio is normalized to 16 kHz, 16-bit, stereo for ReSpeaker Lite compatibility.

## Voice Activity Detection

- **Entry point**: `silero_vad` — Silero VAD model for detecting speech vs. silence
- **Entry point**: `turn_end_detector` — Detects when a user has finished speaking
