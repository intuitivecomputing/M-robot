The `BehaviorGenerator` class uses an LLM to generate coordinated facial expressions and motor primitives for a list of text segments. It demonstrates the pattern for adding LLM-driven behavior generation to any M Platform application.

## Module

- **Package**: `m_examples`
- **Module**: `m_examples.behavior_generator`
- **Class**: `BehaviorGenerator`

## How It Works

1. Accepts a list of text segments (e.g., sentences from a story or conversation)
2. Sends the segments to a Groq LLM with a body-generation system prompt
3. Parses the JSON response into behavior dictionaries
4. Falls back to neutral behaviors if parsing or generation fails

## Output Format

Each generated behavior is a dictionary:

```json
{
  "segmentID": 0,
  "expression": "happy",
  "primitive": "ack_nod"
}
```

- **`segmentID`** — Index of the text segment
- **`expression`** — Face expression name (e.g., `happy`, `sad`, `neutral`)
- **`primitive`** — Motor primitive name (e.g., `ack_nod`, `beat`, `open_encourage`) or `null`

## Configuration

- **LLM Model**: `openai/gpt-oss-20b` (via Groq API)
- **Temperature**: `0.7`
- **Max tokens**: `2000`
- **Reasoning effort**: `low`
- **Prompt file**: `/root/m_ws/src/m_examples/m_examples/prompts/BodyGenPrompt.txt`

## Requirements

- `GROQ_API_KEY` environment variable
- `groq` Python package (`pip install groq`)

## Usage

```python
from m_examples.behavior_generator import BehaviorGenerator

gen = BehaviorGenerator()
behaviors = gen.generate_behaviors(["Hello, how are you?", "Let me tell you a story."])
# [{"segmentID": 0, "expression": "happy", "primitive": "ack_nod"}, ...]
```

## Fallback

If the LLM returns invalid JSON or fails, the generator returns neutral behaviors for all segments:

```python
[{"segmentID": i, "expression": "neutral", "primitive": None} for i in range(len(segments))]
```
